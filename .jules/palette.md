## 2024-05-03 - Replaced TextBlock with TextBox for Logging
**Learning:** For WPF UI logging and frequent text updates, using a `TextBlock` with string concatenation (`+=`) is inefficient due to O(N^2) memory allocations and it is less accessible since users cannot select/copy log text.
**Action:** Replaced `TextBlock` with a read-only `TextBox` and used `TextBox.AppendText()`. To maintain visual consistency, applied `IsReadOnly="True"`, `Background="Transparent"`, `BorderThickness="0"`, `TextWrapping="Wrap"`, and `VerticalScrollBarVisibility="Auto"`. Added `AutomationProperties.Name` and `ToolTip` for accessibility.
