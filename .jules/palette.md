## 2024-03-30 - WPF Accessibility Enhancements
**Learning:** TextBlock elements used as labels in WPF are not accessible to screen readers, and interactive elements need AutomationProperties.Name and ToolTips.
**Action:** Replace TextBlocks functioning as labels with `<Label Target="{Binding ElementName=...}" Padding="0"/>` to maintain visual layout while adding screen reader support, and consistently add `AutomationProperties.Name` and `ToolTip` to inputs, buttons, and progress bars.
## 2024-06-30 - Replace TextBlock with TextBox for large log outputs
**Learning:** Using a TextBlock with string concatenation for logs in WPF creates O(N^2) memory allocations and prevents users from selecting and copying text. This degrades both performance and accessibility.
**Action:** Replace `TextBlock` with `TextBox` for logs. Set `IsReadOnly="True"`, `Background="Transparent"`, `BorderThickness="0"`, `TextWrapping="Wrap"`, and `VerticalScrollBarVisibility="Auto"` to mimic a TextBlock visually while providing native scrolling via `TextBox.ScrollToEnd()` and using `TextBox.AppendText()` to avoid large string allocations. Always remove any redundant `ScrollViewer` wrapper and add proper accessibility attributes like `AutomationProperties.Name` and `ToolTip`.
