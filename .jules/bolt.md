## 2025-02-18 - Optimize WPF TextBlock Logging
**Learning:** Using `TextBlock.Text +=` for logging in WPF creates strings in memory with O(N^2) complexity and triggers layout re-evaluation, causing noticeable lag when logging frequently. This is an anti-pattern for updating large amounts of text.
**Action:** Replace `TextBlock` with `TextBox` for logs and use `TextBox.AppendText()` instead, which is optimized for appending and prevents unnecessary string allocations. Setting `IsReadOnly="True"`, `Background="Transparent"`, `BorderThickness="0"`, `TextWrapping="Wrap"`, and `VerticalScrollBarVisibility="Auto"` mimics `TextBlock`'s appearance while taking advantage of `TextBox`'s superior performance for text updates. Remove surrounding `ScrollViewer` as `TextBox` natively handles scrolling.
