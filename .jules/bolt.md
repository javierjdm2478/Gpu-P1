## 2024-03-24 - WPF Log Re-render Optimization
**Learning:** In WPF, appending text to a `TextBlock` using string concatenation (`+=`) within `Dispatcher.Invoke` causes severe memory allocation overhead (O(N^2)) and synchronous main-thread blocking, which can lag the UI for frequent operations. Additionally, clearing a `TextBlock` by assigning `""` allocates a new string.
**Action:** Replace `TextBlock` with `TextBox` for UI logs. Set `IsReadOnly="True"`, `Background="Transparent"`, `BorderThickness="0"`, and `TextWrapping="Wrap"` to mimic `TextBlock` appearance. Use `TextBox.AppendText()` instead of `+=` to handle log appending natively without creating intermediate strings, and use `TextBox.Clear()` instead of `""`. This also natively supports `ScrollToEnd()` without needing an external `ScrollViewer`.
