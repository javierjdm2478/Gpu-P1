## 2024-05-24 - Avoid O(N^2) memory allocations for logs in WPF UI
**Learning:** For WPF UI logging and frequent text updates, using string concatenation (+=) on TextBlock.Text causes O(N^2) memory allocations.
**Action:** Use TextBox.AppendText() instead of string concatenation (+=) and TextBox.Clear() instead of assigning empty strings. This prevents O(N^2) memory allocations and allows users to select/copy log text. To mimic a TextBlock and ensure proper behavior, set IsReadOnly="True", Background="Transparent", BorderThickness="0", TextWrapping="Wrap", and VerticalScrollBarVisibility="Auto". Remove any redundant surrounding ScrollViewer, since TextBox handles its own scrolling natively via TextBox.ScrollToEnd(). Always include AutomationProperties.Name and ToolTip for accessibility.
