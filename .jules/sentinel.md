## 2024-05-18 - Prevent PowerShell Command Injection
**Vulnerability:** The application was using string interpolation (e.g., `$"Get-VM -Name '{vmName}'"`) to build PowerShell commands and pass untrusted data directly to the command string. Although an attempt was made to sanitize `vmName` using `.Replace("'", "''")`, this approach is insufficient and prone to edge cases, risking command injection.
**Learning:** In C#, constructing commands dynamically via string concatenation/interpolation for `powershell.exe -Command` is a common vector for command injection. Instead of attempting to escape strings, untrusted data must be passed securely.
**Prevention:** Update `RunPowerShellCommand` to accept an `IDictionary<string, string> envVars` parameter, injecting data as `ProcessStartInfo.EnvironmentVariables` and referencing variables securely in the script via `$env:VARNAME`.
