## 2025-03-24 - WMI Data Injection in PowerShell Scripts
**Vulnerability:** Data retrieved from WMI (like `Win32_VideoController`'s `Name` property) was being directly interpolated into a PowerShell script without sanitization. Since it was wrapped in single quotes, an attacker or malformed data containing a single quote could escape the string context and inject arbitrary PowerShell commands.
**Learning:** Even data retrieved from local system resources like WMI must be treated as untrusted input. It should not be inherently trusted just because it originates from the OS rather than a direct user input field.
**Prevention:** Always sanitize untrusted data before interpolation into PowerShell scripts (e.g., by doubling single quotes `input.Replace("'", "''")`) or pass data securely through environment variables instead of script strings.
