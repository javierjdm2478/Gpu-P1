## 2025-06-15 - Command Injection in PowerShell Execution
**Vulnerability:** Execution of PowerShell commands using string interpolation with unescaped, unsanitized user inputs (`vmName`, `vhdxPath`, `name` from GPU detection) is highly vulnerable to command injection.
**Learning:** Even internal tool operations that pass "trusted" variables (like WMI query results or local system state properties) can be dangerous if those properties can be influenced by system state or names that could contain quotes or malicious patterns. Attempting to sanitize manually via string replacements like `Replace("'", "''")` is error-prone.
**Prevention:** Instead of string interpolation for variables inside PowerShell scripts, always use `ProcessStartInfo.Environment` to pass parameters to the process securely, and access them within the PowerShell script using the `$env:VAR_NAME` syntax.
