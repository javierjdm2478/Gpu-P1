## 2024-05-18 - [CRITICAL] Fix command injection in PowerShell execution
**Vulnerability:** The code constructs PowerShell commands using string interpolation (`$"..."`) with unsanitized dynamic user inputs (like `vmName` selected by user) and directly passes the entire string via `-Command` to the `powershell.exe` command line execution. This allows any arbitrary string input ending with a quote to break out and execute destructive or unexpected commands.
**Learning:** String interpolation for inputs dynamically placed in a shell or command-line process should be avoided. The `ProcessStartInfo.Arguments` string is particularly vulnerable.
**Prevention:** Rather than a single format string in `Arguments`, use the `ProcessStartInfo.ArgumentList` collection to isolate arguments. Additionally, sanitize any single quotes from inputs, converting them to double single-quotes (`''`), ensuring parameters are treated solely as arguments to PowerShell command and avoiding injection breaking the quote boundary.
